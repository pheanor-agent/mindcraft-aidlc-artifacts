Design

  1. 기존 P2 자동 연결 항목을 바이브 코딩 지원 관점으로 재정의한다.
  2. 사용자의 workflow를 강제로 바꾸지 않는 비침해형 개입을 기본 원칙으로 둔다.
  3. 의도 감지, Task 연결, CLI/Provider/Model routing, Run 자동 실행을 독립 ToDo로 분리한다.
  4. 개입 시 의도·연결 대상·Knowledge·예상 효과를 설명하고, 위험 작업은 사용자 승인을 요구한다.
  5. 실제 구현은 팀 협업 및 LLM Wiki/TUI 핵심 기능 이후의 최하위 P2로 유지한다.

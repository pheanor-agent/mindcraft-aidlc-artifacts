발표 서체

Noto Sans KR 가변 서체를 원본 TTF로 포함한다. 설치된 시스템 서체에 의존하지 않고 네트워크 없이 동일한 서체를 사용하기 위한 구성이다.

  • 원본: Google Fonts / Noto Sans KR
  • 파일: NotoSansKR.ttf (원본 NotoSansKR[wght].ttf, 수정 없이 파일명만 변경)
  • 라이선스: SIL Open Font License 1.1
  • 시안의 제목: weight 600, letter-spacing 0, font-synthesis none

서체는 슬라이드 디자인과 별도로 동봉된 OFL의 조건을 따른다.

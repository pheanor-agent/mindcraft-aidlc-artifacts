## 현재 본편의 실제 실행 캡처

- `windows-tui-before.png`: Windows 검증 작업의 원본 `windows-tui-task.png`를 이름만 바꿔 복사.
- `windows-tui-fixed.png`: 같은 작업의 실제 수정 후 원본.
- 출처: Mindcraft Windows 빌드 테스트, 2026-09-07, 수정 커밋 `1e3c5317069bb1614e473f6690a35f574bafd710`.
- Windows ConPTY의 실제 Pi TUI를 브라우저 xterm.js에서 캡처했다. AI 생성 이미지가 아니다.
- 본편은 빈 하단을 제외한 상단을 CSS로 표시한다. 원본 바이트는 그대로 보존했고 SHA-256은 상위 source-manifest.json에 남겼다.
- Windows Terminal 앱 또는 한국어 IME 검증의 증거는 아니다.
